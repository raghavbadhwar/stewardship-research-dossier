# Independent five-minute dossier review

The reviewer must not have implemented the dossier or read its source code. Start the timer when the reviewer opens the exported case.

For a 0.3.0 product pilot, the researcher must start from an issuer and question without giving
the system URLs. Before review, record whether every applicable coverage bucket was satisfied,
which gaps the analyst accepted, and the approval timestamp and draft hash.

- [ ] Trace every thesis, counter-view, and risk finding to its exact captured excerpt.
- [ ] Score source authority, issue coverage, longitudinal depth, peer comparability,
  counter-evidence quality, citation fidelity, fact/inference separation, materiality, gap
  honesty, and approval discipline from 1–5.
- [ ] Name the counter-view, whether it contradicts or challenges the thesis, and its linked thesis finding.
- [ ] Identify every uncited captured source and every incomplete issue using diagnostics.
- [ ] Confirm a missing official source or uncited material claim is an automatic revision condition.
- [ ] Confirm the packet contains no investment, engagement, voting, or trading recommendation.

Acceptance requires all checks within 300 seconds, no automatic revision condition, and ratings
of at least 4/5 for clarity and decision usefulness. The reviewer records elapsed seconds, the
two ratings, one useful feature, one material weakness, and the exact failed check when any item fails.
